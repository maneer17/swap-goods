# Swaply Ultra 🔄

A digital platform for exchanging items between users — helping reduce waste 
and encouraging a culture of sharing within the community.

> This project was built as part of the **Codemap training program at Taqat**.

## About

Swaply lets users list items they no longer need and exchange them with other 
users in a simple, organized, and secure way — instead of those items going to 
waste. This repository contains the **backend** of the application, built with 
**Ruby on Rails**.

## The Problem

Many people accumulate unused items at home, while others could actually use 
those same items — but there's no easy, organized way to connect the two sides.

## The Solution

Swaply provides a unified platform where users can list their items and manage 
the exchange process with others, saving time and money while cutting down on 
waste.

## Goals

- Make item exchange simple and accessible
- Reduce waste
- Encourage a culture of collaboration
- Support better use of existing resources

## Getting Started

```bash
git clone <repo-url>
cd swaply-ultra
bundle install
rails db:create db:migrate
rails server
```
